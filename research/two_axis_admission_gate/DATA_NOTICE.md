# HWU64 data notice

SCA-2 uses textual annotations from the official NLU-Evaluation-Data release,
commonly called HWU64. The authors release the data under CC BY 4.0.

- Official repository: <https://github.com/xliuhw/NLU-Evaluation-Data>
- Pinned commit: `f6071b496b17d71e6eb43f543af0707f4ff30557`
- Official processing scripts: <https://github.com/xliuhw/NLU-Evaluation-Scripts>
- Paper: <https://arxiv.org/abs/1903.05566>

The dataset files remain outside Git under
`D:\HLM2\runtime\datasets\hwu64-official`. The tracked manifest contains only
hashes, labels, counts, and row descriptors; it does not redistribute the
utterance text. Fold 2 is sealed from HLM5 encoding until a passing development
verdict and a separate test registration.
