# HLM5 Certified Semantic Attractor Gate

This research package asks one bounded question that the validated feed-forward
HLM5 memory cannot answer:

> Can a genuine polynomial attractor settle improve routing from held-out
> semantic paraphrases over a static cosine cache while producing a replayable,
> monotone energy trajectory?

The current HLM5 reader is already bit-identical to a matched degree-5 cache.
Consequently, this package treats the static reader as the baseline and tests a
new state-dynamics mechanism. Any positive result remains reimplementable as a
generic cache-side optimizer; it is not evidence of proprietary or uniquely
Hopfield computation.

The protocol is frozen in
[`docs/semantic-attractor-gate-prereg-2026-08-10.md`](docs/semantic-attractor-gate-prereg-2026-08-10.md).
Do not run the registered ParaRel assay until the implementation, tests, source
slice, and execution command have been hashed into a registration receipt.

Planned workflow:

1. run unit tests and synthetic preflight only;
2. build the deterministic ParaRel eligibility manifest without model outcomes;
3. hash the protocol, implementation, tests, dataset files, encoder revision,
   environment, and exact command;
4. execute the registered CPU assay once;
5. write a PASS/FAIL/HARNESS_INVALID verdict before changing any scientific
   parameter.

No checkpoint training, language-model forward pass, GPU allocation, or scaling
ladder is authorized by this package.
