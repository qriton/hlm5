# HLM5 canonical intent address gate

This package asks whether deterministic intent-name addresses add task
alignment that nearest-example geometry lacks. The source-only protocol is
fixed in
[`canonical-intent-address-source-protocol-2026-08-10.md`](docs/canonical-intent-address-source-protocol-2026-08-10.md).

The screen may read the already outcome-spent SCA-2 source cache and encode
only canonical labels for the calibration and audit intent groups. It must not
encode the untouched target intent names, target utterances, or official HWU64
fold 2.

The registered source run concluded
[`CLOSED_SOURCE_ONLY`](docs/canonical-intent-address-source-verdict-2026-08-10.md).
All 19 validity gates passed, but raw HLM5 canonical routing missed eight of
nine scientific bars and did not beat its shuffled-label control. The target
intent names and target/test utterances remain unencoded.
